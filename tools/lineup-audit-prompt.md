# 一度きりのタスク：3社の現行ラインアップを公式で洗い直す

あなたは物置比較サイト「物置どれがいい？」のデータ保守担当です。

いま `PRODUCTS` には **18機種**しか載っていません。
ボスが公式サイトを見たところ、**掲載されている機種はその数倍ありました。**
**目的は、指定されたメーカーの現行機種をすべて拾い、抜けを埋めることです。**

対象メーカーは、この指示の最後に書かれた1社だけです。**他社は今回触りません。**

## 触ってよい範囲

- `index.html` の **`PRODUCTS` 配列** と **`UPDATE_LOG` 配列のみ**

**それ以外は1文字も変更しないこと。**
`ARTICLES` 配列・ナビ・セクション構造・スクリプト・CSS・他のファイルには触れない。
**git コマンドは実行しないこと。**

## 手順

### 1. いま何が載っているかを把握する
`index.html` の `PRODUCTS` を読み、対象メーカーの `id` と `name` を書き出す。

### 2. 公式サイトで現行機種を全部拾う
- イナバ物置 https://www.inaba-ss.co.jp/monooki/lineup/
- ヨド物置 https://www.yodomonooki.jp/products/lumberroom/
- タクボ物置 https://www.e-ty.co.jp/seihin/

**物置・収納庫だけでなく、ガレージ・バイク保管庫・大型倉庫・断熱物置も対象です。**
（既存データにも `ガレージ` `バイク車庫` `断熱物置` の `cat` があります）

一覧ページのリンクを1つずつ開いて、**シリーズ単位で**拾ってください。
一覧の見た目だけで判断しないこと。**個別ページを開いて、分類表記と型番を確かめる。**

### 3. 抜けているものを `PRODUCTS` に足す

**既存エントリと同じ形をそのまま真似てください。**新しい書き方を発明しないこと。
`t-pe`（ペインタ）と `y-ese`（エスモ）が見本として読みやすいはずです。

必須：`id` / `maker` / `name` / `cat` / `steel` / `door` / `found` / `look` /
`doorSpec` / `tags` / `features`（3つ）/ `base`（1文）/ `link` / `added`

- `id` … `i-` `y-` `t-` ＋ 型番の記号を小文字で（例 `y-lmd`）
- `cat` … 既存で使われている値から選ぶ。**新しい `cat` を勝手に作らない**
- `elev` … 開口寸法が公式で拾えたときだけ書く。**拾えないなら書かない**
- `sizes` … 型番と外部寸法(w/d/h)。**全型番を拾えたときだけ `sizesComplete:true`。
  一部しか拾えていないなら `sizesComplete:false` にして、拾えたぶんだけ書く**
- `look` の `seen:true` は**ボスが実物を見た機種だけ**に付くものです。
  **今回追加するものは必ず `seen:false`** にしてください
- `base` と `features` は公式の記載にもとづくこと。**使用感・体感は書かない**
  （ボスは下請けで施工のみ。使ってはいない）

### 4. 色違い・コラボは `variant` を付ける

**別機種として載せる。**ただし `variant` を必ず付けること。
付けると索引カードに印が出て、診断の候補からは自動的に外れます。

```javascript
variant:{ of:'y-lmd', kind:'色違い' },
```

例：ブラックエスモ → `variant:{ of:'y-ese', kind:'色違い' }`

### 5. 公式から消えているものを見つけたら

**消さないでください。**報告文に「公式で見つからなかった」と書くだけにする。
廃盤の判断はボスがします。

### 6. `UPDATE_LOG` に1件足す

先頭に追加。`body` は**300〜600字**で、次の4つを必ず入れること。

1. **何が変わったのか**（今回は「載っていなかった現行機種を足した」）
2. **具体的に何を足したか**（シリーズ名を並べる）
3. **なぜ今まで無かったのか／どこを見れば分かるのか**
4. **読む人にとって何が変わるのか**（診断や比較でどう効くか）

**箇条書きにしない。文章で書く。**
禁止表現：「〜がおすすめです」「〜は重要です」「一般的には〜」「〜と言われています」

## 最後に、報告文を出す

作業が終わったら、画面に次の3つを出してください。

1. **足した機種**（`id` と `name`。何件か）
2. **見送った機種と、その理由**（判断がつかなかったもの。必ず列挙する）
3. **公式で見つからなかった既存機種**（あれば）
