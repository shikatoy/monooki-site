# タスク：1シリーズの寸法を取り切る

`index.html` の `PRODUCTS` にある **1機種だけ**を対象に、
**全型番の外形寸法（間口・奥行・高さ）を公式から取り切ります。**

対象の `id` は、この指示の最後に書いてあります。**他の機種は1文字も触らないこと。**

## これだけをやる

- 対象機種の `sizes` を、公式で確認できた型番で**入れ替える**
- 全型番を取り切れたら `sizesComplete:true`、一部なら `false`

**やらないこと**（今回の対象外。見つけても手を出さない）
- 新しい機種を `PRODUCTS` に足す
- 他機種の修正
- `UPDATE_LOG` の追記
- 記事・他ファイルの変更
- git コマンド

## なぜこれが要るか

サイトの診断と「寸法から探す」ページは、この `sizes` だけを見ています。
**型番が抜けていると、実在する物置が候補に出てきません。**
例：タクボ Mr.ストックマン ダンディは掲載が間口1832mmからでしたが、
公式のサイズバリエーションは**1316mm** から。ここに入る人に「該当なし」と答えていました。

**機種を増やすことより、寸法を取り切ることが目的です。**

## 手順

1. `index.html` を Read し、対象機種の現在の `sizes` と `link`（公式URL）を確認する
2. 公式サイトで**全型番の一覧**を探す。シリーズ紹介ページには無いことが多い。次を順に開く
   - サイズ一覧・サイズバリエーションのページ（`.../size.html` など）
   - 各型番の個別ページ
   - 電子カタログ・WEBカタログ
   - データダウンロードの寸法表PDF・外形図面PDF
   **「ページに書いていなかった」で終わらせないこと。**
3. 型番ごとに **間口(w)・奥行(d)・高さ(h)** を mm で拾う
   - **高さが取れない型番は入れない。**取れるまで探すか、その型番は落とす
   - 一般型／多雪型（積雪地型・豪雪型）で型番が分かれているなら**両方入れる**
   - 扉違い・色違いで型番が分かれるなら、それも型番として入れる
4. `sizes:[ { code:'...', w:0, d:0, h:0 }, ... ]` の形で書き戻す
   （既存エントリと同じ1行の書き方に合わせる）
5. 取り切れたかどうかで `sizesComplete` を立てる

## 事実の扱い

- **メーカー公式だけ。**販売店・通販サイト・ブログの寸法は使わない
- 数字は公式の表記のまま。四捨五入や丸めをしない
- 迷ったら入れない。**間違った寸法が1件入るほうが、抜けているより害が大きい**

## 最後に報告する

1. 対象機種と、**型番数（前 → 後）**
2. `sizesComplete` を true にしたか、しなかったならその理由
3. **どこから取ったか**（開いたページ・PDFのURL）
4. 落とした型番があれば、型番名と落とした理由
5. 公式で一般型／多雪型が分かれていたか
