## PDFの読み方（この環境での手順）

クラウド側の `bash` と `device_bash` は、3社のドメインすべてで**プロキシが403**を返します。
**Chrome拡張の `javascript_tool` から同一オリジンで `fetch` するのが唯一の経路**です。

1. 対象ドメインのページへ `navigate`（別オリジンからの `fetch` は CORS で落ちます）
2. pdf.js 3.11.174 を cdnjs から注入
3. `fetch` → `getDocument` → 全ページの `getTextContent`
4. 結果を `window.__pdf` に入れて、**あとから小分けに取り出す**
   （CDPは45秒で切れ、戻り値は約1000文字で切れます。投げっぱなしにして後で見る形にします）
