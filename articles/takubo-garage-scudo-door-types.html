タクボのガレージは、扉だけが違う

ベルフォーマスクードとカールフォーマスクードは、間口・奥行・高さの組み合わせが完全に同じで、違うのは扉だけです。オーバースライド扉と巻上げシャッター扉の使い分けと、型番から扉と寸法を読む方法をまとめました。

ベルフォーマスクード カールフォーマスクード 違い タクボ ガレージ 扉 種類 オーバースライド扉 シャッター 違い タクボ ガレージ 型番 読み方 ガレージ 扉 選び方

タクボのガレージ「ベルフォーマスクード」と「カールフォーマスクード」は、名前も見た目もよく似ています。カタログを並べても、どこが違うのか分かりにくい。

公式のサイズ表を突き合わせてみたところ、理由がはっきりしました。寸法の選択肢が、完全に同じなのです。

違うのは扉だけです。だから迷うとしたら、そこ一点になります。

この記事は、メーカー公式サイトの記載を突き合わせて書いています。私自身がこの2機種を据えた経験にもとづくものではありません。据えてみて分かることは、また別にあります。

寸法の選択肢が完全に一致している

公式のサイズ表は、2機種とも次のようになっています。

| | 選べる値 | |---|---| | 間口 | 2,774 / 3,124 / 3,474 mm | | 奥行 | 5,432 / 6,132 / 6,648 mm | | 高さ | 2,450 / 2,763 / 3,250 mm |

そして、間口と奥行の組み合わせにも同じ制限がかかっています。

  • 奥行 5,432 … 間口は 2,774 と 3,124 のみ（最大の 3,474 は選べない）
  • 奥行 6,132 … 間口は3つとも選べる
  • 奥行 6,648 … 間口は 3,124 と 3,474 のみ（最小の 2,774 は選べない）

短い奥行では一番広い間口が選べず、長い奥行では一番狭い間口が選べません。この制限も2機種で同じです。

結果として、型番はどちらも21通り。数も組み合わせも一致しています。

つまり「置ける寸法で絞ったら片方に決まる」ということが起きません。寸法で決着がつかない以上、扉で決めることになります。

型番から、扉と寸法が読める

この2機種の型番は、意味が決まっています。覚えると、型番を見るだけで扉と大きさが分かります。

``` X S - 27 53 │ │ │ └─ 奥行 5432 │ │ └──── 間口 2774 │ └───────── 高さ 2450 └─────────── オーバースライド扉 ```

  • 1文字目 … `X` はオーバースライド扉（ベルフォーマスクード）、`Y` は巻上げシャッター扉（カールフォーマスクード）
  • 2文字目 … `S` = 高さ2,450 / `M` = 高さ2,763 / `L` = 高さ3,250
  • 数字の前2桁 … 間口（27＝2,774 / 31＝3,124 / 34＝3,474）
  • 数字の後2桁 … 奥行（53＝5,432 / 60＝6,132 / 65＝6,648）

`XM-3160` なら、オーバースライド扉・高さ2,763・間口3,124・奥行6,132。`YM-3160` は、それとまったく同じ寸法で扉だけが巻上げシャッターという意味になります。

見積書や図面で型番だけ書かれていても、これで中身が分かります。

扉の違いは、収まる場所の違い

扉の形式が違うと、開けたときに扉がどこへ行くかが変わります。

オーバースライド扉は、扉全体が一枚の板のまま、天井に沿って奥へ滑り込みます。公式の説明でも「天井に沿って収納される」とされています。扉を収めるぶんの天井まわりが埋まります。

巻上げシャッター扉は、開口部の上でシャッターが巻き取られます。天井に沿って伸びていかないぶん、開けたあとの天井は空いたままになります。

どちらが良いという話ではなく、天井まわりを何に使うかで分かれます。天井際に棚や吊り下げ収納を考えているなら、扉がそこを通るかどうかは先に確かめておく材料になります。

なお、公式のコピーは「静かで丈夫」という説明を2機種まとめて当てています。どちらの扉が静かか、という比較は公式には書かれていません。開閉音や操作感の差については、ここでは触れないでおきます。

選ぶときに見ておくこと

寸法で決まらない以上、判断の材料はこのあたりになります。

  • 天井まわりを使う予定があるか … あるなら、扉が通る範囲を先に確認する
  • 型番の頭文字 … `X` と `Y` を見間違えると、同じ寸法で扉だけ違うものが届く
  • 奥行と間口の組み合わせ制限 … 置き場所の形によっては、選べる高さが先に決まることがある

寸法・型番・扉形式は、いずれもメーカー公式サイトで公開されています。実際の動きやオプションについては、公式の電子カタログに詳しい記載があります。

まとめ

ベルフォーマスクードとカールフォーマスクードは、間口・奥行・高さの選択肢も、その組み合わせ制限も、型番の数も同じでした。違いは扉の形式だけです。

  • オーバースライド扉（`X`）… 扉が天井に沿って収まる
  • 巻上げシャッター扉（`Y`）… 扉が開口部の上で巻き取られる

寸法で絞っても片方には決まりません。天井まわりをどう使うかが、実質的な分かれ目になります。
